# 校园失物招领平台

> 两人协作 · 14 天开发 · 交互设计优先
>
> 开发周期：**2026-11-16 至 2026-11-29**  
> 当前阶段：开发前准备  
> 目标：交付一个可实际操作、主流程闭环、视觉统一且适合现场演示的校园失物招领 Web 平台。

## 1. 项目定位

面向校园师生，提供失物发布、拾物招领、信息搜索筛选、认领/线索申请、申请处理和物品归还状态跟踪。项目评价中交互设计占 90%，因此开发优先级为：**交互流程完整 > 页面信息组织清晰 > 视觉一致与精致 > 非必要功能数量**。

场景视频已由团队准备，不纳入开发任务；最终验收只检查视频播放、视频内容与系统实际功能是否一致。

## 2. 已统一的技术决策

| 层次 | 统一方案 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite |
| UI | Element Plus（基础控件）+ SCSS/CSS Design Tokens（视觉定制）+ lucide-vue-next（图标） |
| 路由/状态 | Vue Router 4 + Pinia |
| HTTP | Axios，统一 API 封装 |
| 后端 | Node.js 26 LTS + Express 5 + TypeScript |
| 数据库 | MySQL 8.4 LTS |
| ORM/校验 | Prisma ORM + Zod |
| 身份认证 | JWT Bearer Token + bcrypt |
| 文件 | Multer，本地文件目录存储 |
| API 文档 | `docs/05_API接口规范文档.md` + `api/openapi.yaml` |

不在开发中途更换技术栈。Node.js 26 在本项目准备时处于 LTS 线；MySQL 8.4 为 LTS 系列。参考： [Node.js Release](https://nodejs.org/en/about/previous-releases)、[MySQL 8.4 LTS 说明](https://dev.mysql.com/doc/refman/8.4/en/mysql-releases.html)。

## 4. 核心页面

1. 首页：平台介绍、快捷入口、分类导航、最新失物/招领。
2. 信息广场：寻物/招领切换、关键词搜索、分类/地点/状态筛选、排序、分页。
3. 信息详情：图片、描述、时间地点、发布者摘要、状态、认领/线索操作。
4. 发布信息：寻物/招领类型切换、字段校验、图片上传预览。
5. 个人中心：我的发布、我提交的申请、我收到的申请、状态处理。
6. 登录/注册页。
7. 管理员基础页面（P1，有余力再做）。

## 5. 开始开发

开发环境和启动命令以 `docs/10_环境配置与部署说明.md` 为准。前端不得自行臆造后端字段；后端不得自行改变接口响应。接口不完整时先按 API 文档补齐契约，再继续编码。
