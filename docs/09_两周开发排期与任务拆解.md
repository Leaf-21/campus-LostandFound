## 6. 延误时的砍功能顺序

优先保证：注册登录 → 信息广场/详情 → 发布 → 申请提交 → 申请处理 → 完成状态 → 个人中心 → UI 精修。

如出现延误，先砍 P1 管理员页面、资料编辑、撤回申请、关闭信息；不砍 P0 闭环，不牺牲核心页面交互质量。场景视频已准备，不安排制作占用人力。
