## 2. 本地开发（浏览器直接操作）

### 2.1 环境要求

| 组件 | 版本 |
|---|---|
| Node.js | 26 LTS（仓库根 `.nvmrc` 固定为 `26`） |
| MySQL | 8.2+（推荐 8.4 LTS） |

### 2.2 启动 MySQL

本项目开发机使用 **3307** 端口的独立实例（与系统 3306 实例并存，互不影响），**不设开机自启**：

```powershell
# 开发前启动（幂等，已在运行则跳过）
powershell -ExecutionPolicy Bypass -File D:\dsh_project\.tools\start-mysql-lf.ps1

# 结束开发后可选停止
powershell -ExecutionPolicy Bypass -File D:\dsh_project\.tools\stop-mysql-lf.ps1
```

首次建库：

```sql
CREATE DATABASE campus_lost_found      CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE campus_lost_found_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2.3 启动后端

```bash
cd backend
npm ci
cp .env.example .env      # 按需修改 DATABASE_URL / JWT_SECRET / 密码
npm run prisma:generate
npx prisma migrate deploy # 应用全部迁移
npm run prisma:seed       # 写入演示数据（幂等）
npm run dev               # http://localhost:3000
```

验证：`curl http://localhost:3000/health` → `{"code":0,...,"status":"UP"}`

### 2.4 启动前端

```bash
cd frontend
npm ci
cp .env.example .env
# 联调真实后端：VITE_USE_MOCK=false，VITE_API_BASE_URL=http://localhost:3000/api/v1
npm run dev               # http://localhost:5173
```

### 2.5 打开浏览器操作

访问 **http://localhost:5173**，用下列账号登录即可完整操作：

| 账号 | 角色 | 密码来源 |
|---|---|---|
| `student2026` | 普通用户（主演示） | `.env` 的 `DEMO_USER_PASSWORD`，默认 `Passw0rd!` |
| `azhe2026` / `orange2026` / `xiaobei2026` / `anan2026` | 普通用户 | 同上 |

> 生产环境必须替换 `ADMIN_PASSWORD`、`DEMO_USER_PASSWORD`、`JWT_SECRET`；应用在 `NODE_ENV=production` 下会拒绝示例密钥启动。


> **依赖完整性提醒**：`multer`、`prisma`、`tsx` 必须保留在 `dependencies`（非 devDependencies）。

## 5. 对外演示部署（可选，裸机方式）

按 docs/10 §6，不使用容器，直接部署到一台能同时运行 Node 与 MySQL 的云主机/实验室服务器：

```bash
# 后端
cd backend
npm ci
npx prisma generate
npm run build
npx prisma migrate deploy
npm run prisma:seed          # 仅首次
NODE_ENV=production node dist/server.js   # 建议用 pm2 托管

# 前端
cd frontend
npm ci
npm run build                # 产物在 frontend/dist
```

Nginx 参考配置：

```nginx
server {
  listen 80;
  server_name your-domain.com;

  # 前端静态资源
  root /var/www/campus-lost-found/frontend/dist;
  index index.html;
  location / { try_files $uri $uri/ /index.html; }

  # 后端 API 反向代理
  location /api/ { proxy_pass http://127.0.0.1:3000; proxy_set_header Host $host; }
  # 上传图片
  location /uploads/ { proxy_pass http://127.0.0.1:3000; }
  # 健康检查
  location = /health { proxy_pass http://127.0.0.1:3000; }
}
```

要点：
- MySQL 只监听本机，**不对外暴露 3306**。
- `CORS_ORIGIN` 改成真实前端域名；`PUBLIC_BASE_URL` 改成真实地址（用于拼上传图片绝对 URL）。
- HTTPS 环境把 `VITE_API_BASE_URL` 写成 `https://...` 并在构建时注入。
