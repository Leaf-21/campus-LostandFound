## 一、项目视觉方向

| 维度 | 决策 | 说明 |
|---|---|---|
| 定位 | 移动端优先的校园失物招领 H5 | 手机扫码即可演示，桌面端同样可用 |
| 关键词 | 清新、可信、高效 | 失物场景需要信任感与低焦虑 |
| 主色 | `#176B5B`（沉稳深绿） | 可信、校园感，用于主按钮与关键强调 |
| 辅助色 | `#E8F4EF`（浅绿底） | 徽章底、选中态、区块背景 |
| 强调色 | `#E98A45`（暖橙） | 仅用于行动召唤与酬谢信息，克制使用 |
| 中性色 | 正文 `#1F2A27` / 次文 `#65736E` / 边框 `#E3EAE6` / 底色 `#F7F9F7` | 保证文字层级 |
| 形状 | 卡片圆角 14–18px，控件 8–10px | 柔和但不过度卡通 |
| 图标 | lucide 线性图标 | 与整体轻盈风格一致 |
| 状态表达 | 颜色 + 文字双重编码 | 颜色不作唯一状态区分（无障碍要求） |
| 响应式 | 桌面 3 列 → 窄屏 2 列 → 移动 1 列；内容最大宽 1200px | 1366px 与 390px 均无横向滚动 |

以上 Token 已在 `frontend/src/styles/tokens.scss` 落地为 CSS 变量并映射 Element Plus 变量。

## 二、页面地图（Sitemap）

```
校园失物招领
├── /                首页（Hero + 分类入口 + 最新发布 + 使用指南）
```

## 三、导航与页面结构

- **全局框架**：粘性顶部导航（Logo、信息广场、发布信息、用户区）+ 页脚（平台说明 + 安全提示）；移动端导航折叠为抽屉。
- **用户区**：未登录显示「登录」；已登录显示头像下拉（个人中心 / 退出登录）。
- **路由守卫**：`/publish`、`/posts/:id/edit`、`/me` 需登录，未登录跳 `/login?redirect=原地址`，登录后回跳。
- **公共组件**（已实现 16 个）：AppHeader / AppFooter / HeroSection / PostTypeTabs / CategoryGrid / PostCard / PostGrid / PostFilters / FilterChips / StatusBadge / LoadingSkeleton / EmptyState / ErrorState / ConfirmActionDialog / ApplicationFormDialog / ApplicationCard / ImageUploader / ImageGallery。

## 四、核心用户流程

### 1. 失主发布寻物（LOST）

```
登录 → 首页/导航「发布信息」→ 选择类型[寻物] → 填写标题/分类/地点/发生时间/描述/酬谢/图片
     → 校验通过 → 提交 → 跳转详情页（状态：正在寻找）→ 其他同学可提供线索
```

### 2. 拾主发布招领（FOUND）

```
同上，类型选择[招领] → 详情页状态：等待认领 → 其他同学可提交认领申请
```

### 3. 认领/线索闭环（核心链路）

```
浏览/搜索/筛选 → 详情页
  ├─ FOUND 信息 → 提交认领申请（描述 10–500 字）
  └─ LOST 信息 → 提供线索（描述 10–500 字）
       ↓
发布者收到申请（个人中心/详情页，待处理优先）
  ├─ 接受 → 信息进入「处理中」，其余待处理申请自动拒绝
  │         → 双方联系线下交接 → 发布者「确认完成交接」→ 信息「已解决」
  └─ 拒绝（可附说明）→ 申请人可重新提交
```

**业务规则冻结**（与 docs/05 一致）：LOST 只能提线索、FOUND 只能提认领；不能申请自己发布的信息；同一用户对同一信息仅允许一条 PENDING/ACCEPTED 申请；申请人可撤回 PENDING 申请。

### 4. 申请状态机

```
提交 ──→ PENDING ──接受──→ ACCEPTED ──交接完成──→ COMPLETED
   │        │ 拒绝
   │        └──────→ REJECTED（可重新提交，回到 PENDING）
   └──撤回──→ CANCELLED（可重新提交，回到 PENDING）
```

### 5. 信息状态机

```
OPEN（正在寻找/等待认领）──发布者接受申请──→ PROCESSING（处理中）
                                              │ 交接完成
                                              ↓
                                          RESOLVED（已解决）
OPEN ──发布者关闭/超期/违规──→ CLOSED
违规下架 ──→ HIDDEN
```

### 6. 登录/注册流程

```
未登录访问需登录页 → 跳 /login?redirect=… → 登录成功回跳 → 会话存 sessionStorage
注册：账号(4–20)/昵称(2–20)/邮箱(选填)/密码(8–20) → 成功 → 登录页回填账号
401 过期 → 清会话 → 跳登录（带当前地址，登录后回跳）
```
