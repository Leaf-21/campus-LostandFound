# 11｜开发前检查清单

> 本清单用于 2026-11-16 开发启动前确认。完成后即可按排期并行编码。

## A. 项目决策

- [ ] 两人已阅读 `00_开发前统一决策.md`。
- [ ] 已确认项目名、开发周期和两人职责。
- [ ] 已确认 P0/P1 范围及明确不做的功能。
- [ ] 已确认场景视频已准备，不安排重新制作。
- [ ] 已确认 API 端口、前端端口和数据库端口。

## B. 技术环境

- [ ] 两人本机 Node.js 均为 26 LTS。
- [ ] 两人均安装 Git、npm、MySQL 8.4 LTS。
- [ ] 双方能访问 GitHub 仓库。
- [ ] 已创建 `frontend/`、`backend/`、`docs/`、`api/`。
- [ ] `.gitignore` 已排除 `.env`、`node_modules`、`dist`、真实上传图片。

## C. 接口和数据

- [ ] 已确认 API Markdown 和 OpenAPI YAML 路径一致。
- [ ] 已确认 `LOST/FOUND`、PostStatus、ApplicationStatus 枚举。
- [ ] 已确认用户、信息、图片、申请、分类数据结构。
- [ ] 已确认统一响应格式和业务错误码。
- [ ] 已确认分页、时间、ID、图片限制。
- [ ] 已确认接受申请和完成交接的事务规则。

## D. UI/交互准备

- [ ] 已确认首页、广场、详情、发布、个人中心、登录注册页面清单。
- [ ] 已确认桌面端和移动端适配目标。
- [ ] 已确认颜色、字号、间距、卡片和状态标签规范。
- [ ] 已确认 Loading/Empty/Error/Success/Disabled 状态要求。
- [ ] 已确认真实场景演示数据的准备人。

## E. GitHub 协作

- [ ] `main` 分支保护或人工禁止直接推送规则已明确。
- [ ] PR 模板已加入仓库。

- [ ] 两人已确认分支和提交命名规范。
- [ ] 已安排每天 20:30（Asia/Shanghai）进度同步。
