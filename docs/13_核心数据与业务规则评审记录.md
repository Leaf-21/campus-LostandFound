### 2.2 枚举（三处一致：04 §4 = 05 §3 = 01 §4）

| 枚举 | 值 |
|---|---|
| postType | LOST / FOUND |
| postStatus | OPEN / PROCESSING / RESOLVED / CLOSED / HIDDEN |
| applicationType | CLAIM（对 FOUND）/ CLUE（对 LOST），由 postType 自动决定，前端不得传错组合 |
| applicationStatus | PENDING / ACCEPTED / REJECTED / CANCELLED（P1）/ COMPLETED |
| role | USER / ADMIN |
| sort | LATEST / OLDEST |

### 2.3 状态机与事务（04 §5 = 05 §3.4 = 01 §6）

- OPEN → PROCESSING（接受一条 PENDING 申请）；PROCESSING → RESOLVED（完成交接）；OPEN → CLOSED（P1）；任意非 RESOLVED → HIDDEN（P1 管理员）；HIDDEN → 隐藏前状态（P1）。
- 接受事务：单事务内校验 Post=OPEN、目标 Application=PENDING、操作者=发布者 → 目标 ACCEPTED + reviewed_at → 同帖其余 PENDING 自动 REJECTED → Post=PROCESSING，提交后返回最新状态。
- 完成事务：校验 Post=PROCESSING、Application=ACCEPTED、操作者=发布者 → Application=COMPLETED + completed_at → Post=RESOLVED + resolved_at。
- 拒绝：仅 PENDING → REJECTED，Post 保持 OPEN；重复处理非 PENDING 申请返回 409。
- 并发：有效申请唯一性（同用户同帖至多一条 PENDING/ACCEPTED）由 service 事务检查；条件更新防重复点击（08 §2）。

### 2.4 权限矩阵（08 §3 与 05 各接口鉴权标注一致）

| 场景 | 预期 |
|---|---|
| 游客发布/申请/处理 | 401 / 40101 |
| 编辑他人信息、处理他人收到的申请、申请自己的信息 | 403 / 40301 |
| 不存在资源 | 404 / 40401 |
| 失效 Token | 401，前端清会话 |
| 普通用户访问 /admin/* | 403 |
| 第三方读取申请详情 | 403/404（仅申请人、发布者、管理员可见） |

### 2.5 全局约定

- 响应统一 { code, message, data, requestId }；业务码表 05 §2.6 完整无缺漏；HTTP 状态映射一致。
- 分页 page=1 / pageSize=12 / max 50；items 空数组不为 null；totalPages=ceil(total/pageSize)。
- 密码仅 bcrypt 哈希，任何响应不回传；phone/email 不进入公开列表/详情；reviewNote 仅申请双方可见。
- 图片白名单 JPG/JPEG/PNG/WEBP、单张 ≤5MB、每帖 ≤5 张，服务端查 MIME+扩展名；拒绝 HTML/SVG/可执行文件。
- 04 各字段 DB 容量均 ≥ 应用层限制（title VARCHAR(100)≥50、description TEXT≥1000、location VARCHAR(120)≥100、reward VARCHAR(255)≥100、details VARCHAR(1000)≥500、review_note VARCHAR(500)≥200），无不足。
- 索引建议（04 §2.3/2.5）齐备：posts(post_type,status,created_at)、(category_id,status)、(publisher_id,created_at)、(location)；applications(post_id,status)、(applicant_id,created_at)、(post_id,applicant_id)。关键词首版 LIKE，不引入全文检索。

## 5. 11/18 实现输入清单（I-04：schema/迁移/Seed）

> 以本清单 + 04 修正后文本为准编写 prisma/schema.prisma；D1/D9 确认后纳入。

- generator prisma-client-js；datasource mysql，url=env("DATABASE_URL")；连接串建议 ?connection_limit=10。
- 模型命名 PascalCase（User/Category/Post/PostImage/Application，确认后 + UploadedFile/AdminAction），@@map 到 snake_case 表名，字段 @map 到 snake_case。
- id String @id @default(uuid()) @db.Char(36)；时间 DateTime @db.DateTime(3)，created_at @default(now())、updated_at @updatedAt。
- 枚举：Role、PostType、PostStatus、ApplicationType、ApplicationStatus（MySQL 原生 ENUM）。
- 唯一约束：users.account；categories.code、categories.name；applications 有效唯一性走 service 事务（不加 DB 部分唯一索引，MySQL 不支持）。
- 索引按 §2.5 清单 @@index；外键 onDelete：PostImage→Post 用 Cascade（仅元数据），其余 Restrict（保留历史）。
- 分类 Seed 固定六项（04 §2.2）：数码产品 DIGITAL、证件卡类 CARD、书籍文具 BOOK、生活用品 DAILY、衣物配饰 CLOTHING、其他 OTHER；sort_order 按展示顺序；upsert by code，可重复执行。
- 演示 Seed：管理员（ADMIN_ACCOUNT/ADMIN_PASSWORD，bcrypt）+ ≥2 演示用户（D7 确认后读 DEMO_USER_PASSWORD）+ 覆盖 LOST/FOUND、OPEN/PROCESSING/RESOLVED 的帖子与申请样例（08 §5 用例 A/B、01 §9），图片用占位 URL；全部 upsert/幂等。
- 迁移：npx prisma migrate dev --name init；生产 migrate deploy；迁移文件提交 Git。
- 应用层校验（Zod）与 DB 容量分层：校验按 05 数值（C1–C3 修正后），DB 容量按 04。
